# 企业用电分析工具

## 部署到 Streamlit Community Cloud
1. 将本目录全部文件（含 .streamlit/config.toml）上传到自己的 GitHub 私有仓库。
2. 访问 https://share.streamlit.io/ 并登录，连接 GitHub。
3. Create app → 选择仓库与分支，入口 app.py；Advanced settings 选择 Python 3.12。
4. 部署后在应用设置确认访问权限为 Private，按邮箱邀请使用者。
5. 分享部署成功后返回的 https://名称.streamlit.app 网址。

不要把企业数据、密码或 secrets.toml 上传到仓库。

## 使用
上传江苏电表示数 xls/xlsx → 点击开始计算 → 查看结果并下载。
多文件独立作为不同企业处理。变更输入立即清空旧结果。

## 计算口径
各表相邻示数差分乘综合倍率后按日合并；缺日按查询范围补零。
负值置零并默认排除异常电表日；存在排除电表的企业日不参与比例计算。
08:00–16:00 对应 9–16 时差分电量。
每小时跨日期日均电量 / 全天日均电量得到每小时占比。
八个小时的日均电量之和 / 全天日均电量得到目标时段占比。
预计年用电量 = 全天日均电量 × 365。

## 数据处理
上传文件经云服务器处理，代码不主动将上传文件写入磁盘或数据库。
每个浏览器会话独立保存当前计算结果；不提供跨会话历史记录。
平台自身的数据和运行策略仍适用。
